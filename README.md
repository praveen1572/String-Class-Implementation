# String Class Implementation

A custom C++ String class implemented from scratch using dynamic memory, operator overloading, deep copying, and custom string manipulation functions without using `std::string`.

## Features

- Dynamic character array
- Default constructor
- Parameterized constructor
- Copy constructor
- Destructor
- Assignment operator `=`
- Concatenation operator `+`
- Subscript operator `[]`
- Comparison operators:
  - `>`
  - `<`
  - `>=`
  - `<=`
  - `==`
  - `!=`
- Stream operators:
  - `<<`
  - `>>`

## Custom String Functions

The project implements:

- `strlen()`
- `strcpy()`
- `strncpy()`
- `strcmp()`
- `strncmp()`
- `strcat()`
- `strncat()`
- `strrev()`
- `strupr()`
- `strlwr()`
- `strchr()`
- `strrchr()`
- `strstr()`

## Concepts Used

- Classes and objects
- Dynamic memory allocation
- Constructors and destructor
- Copy constructor
- Deep copying
- Operator overloading
- Friend functions
- Pointers
- Character arrays
- C-style strings
